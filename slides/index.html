Background · conformal inverse optimization (CIO)

How big a set? Let held-out decisions decide

Lin, Delage & Chan (2024), Fig. 1, conformal half (cropped) · CC BY 4.0

A set explains a decision if some objective in it makes that decision optimal.

Grow the set (radius q) until it explains at least γ = 80% of held-out decision makers.

Then it explains the next one with probability ≥ γ, averaged over i.i.d. decision makers.

How big should the set be? CIO lets held-out data decide. A set explains a decision if some objective in it makes that decision optimal. Grow the set, with radius cue, until it explains at least gamma, say eighty percent, of the held-out decision makers. Conformal prediction then guarantees it explains the next one with probability at least gamma. In IRL, each decision maker is one demonstrator. Most of the pipeline carries over. The distance score and the robust decision must be rebuilt.

First, the distance score. CIO measures an angle between reward vectors. But stretching the features changes no reward value and no policy, yet the calibrated angular radius moves by twenty-four point three degrees on average. Ours stays put: essentially zero. We measure a reward difference vee by the spread of policy values it creates. The D-norm of vee is the best policy value under vee, minus the worst. It is the smallest distance that bounds regret, and the score is still one linear program.
What is certified

Touching ≠ containing the true reward

With probability ≥ 80%, the calibrated set touches the rewards that explain a new demonstrator. That demonstrator’s own reward, the true reward ★, need not be inside.

Span score, same radius q, 95% intervals.
The gap comes from which distance is scored, not sample size: more calibration data won’t close it.

Second, what the guarantee actually says. The gray wedge holds every reward that explains a new demonstrator. The star is the reward they actually use, their true reward. With probability at least eighty percent, the calibrated set touches the wedge, but here it misses the star. At an eighty-percent target we measure eighty-two percent for touching and only forty-four for containing. The gap comes from which distance is scored, so more data won't close it. CIO already states this touching guarantee. The question is what it buys.
From touching to containing

Pay for the gap: R = 2q + η (capped at 2)

From the estimate to the true reward, in three steps:

≤ qreach a reward that explains the behavior

≤ qrescale it to unit scale, where rewards are compared

≤ ηmove across the explaining rewards (orange): their certified width

Pr[ true reward within R of the estimate ] ≥ γ

Known tabular MDP; exactly optimal, fully observed, i.i.d. demonstrators; certified η (CIO’s diameter bound, adapted). Unit-scale rewards; marginal probability.

To contain the true reward, we pay for the gap explicitly. Some explaining reward is within cue of the estimate. Rescaling it to unit scale costs at most cue more. Moving across the explaining rewards costs at most eta, their certified width. So, with R equal to two-cue plus eta, the probability that the true reward lies within R is at least gamma.
Rebuilt 2 · the robust decision

Decide against a fixed baseline

Curve: a one-state toy with 16 actions, fixed center, uniform baseline (added after acceptance).

Choose the policy with the best worst-case gain over a baseline: a reference policy fixed in advance.

If the set contains the true reward, its expected return is at least the baseline’s.

At R ≥ 1 the set contains the zero reward, under which every policy ties, so the worst-case gain is zero.

No width certificate (η = 2, the maximum): safe, but it just returns the baseline.

Finally, we choose the policy with the best worst-case gain over a baseline, a reference policy fixed in advance. If the set contains the true reward, we never do worse than that baseline. But bigger sets mean smaller gains. Once R is at least one, the set contains the zero reward, every policy ties, and the gain is zero. Without a width certificate, eta is two, and the method safely returns the baseline. In a small toy where eta is computed exactly, R is zero point seven eight and the certified gain is zero point one one.

Calibrate-then-decide needs three separate answers

Whenever behavior only partially identifies what we want to know:

1

Which geometry?

Measure distances by their effect on decisions, not in coordinates.

2

Which quantile?

Standard split conformal; it transfers unchanged.

3

Which event?

Touching is not containing: certify the width η, or say what is missing.
